# TELMAINT shop assets

CDN delivery для GLB 3D-моделей и WebP-фотографий.

URL формат:
  https://cdn.jsdelivr.net/gh/vladbatin97-sys/telmaint-shop-assets@main/models/<file>.glb
  https://cdn.jsdelivr.net/gh/vladbatin97-sys/telmaint-shop-assets@main/photos/<file>.webp

Источник — private repo `vladbatin97-sys/telmaint`, путь `shop/public/{models,photos}/`.
Sync вручную или через CI после правок Blender pipeline / image processing.
